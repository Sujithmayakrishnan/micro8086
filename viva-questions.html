UNIT I : 8086 : A 16-bit Microprocessor

Basics and Salient Features

  1. Q1.

    What is a microprocessor?

    Ans: A microprocessor is a program-controlled semiconductor device (IC) which fetches, decodes and executes instructions.

  2. Q2.

    What are the basic functional blocks of a microprocessor?

    Ans: ALU (Arithmetic and Logic Unit), an array of registers and the control unit.

  3. Q3.

    What is a bus? Name the three types of buses.

    Ans: A bus is a group of conducting lines that carries data, address and control signals. The three buses are the address bus, data bus and control bus.

  4. Q4.

    Why is the data bus bidirectional?

    Ans: The processor must read data from memory/input devices and also write data to memory/output devices, so data flows in both directions.

  5. Q5.

    Why is the address bus unidirectional?

    Ans: The address is always sent out by the processor to select a memory location or IO device; it is only an output from the processor.

  6. Q6.

    What is multiplexing? What is its advantage?

    Ans: Multiplexing is sending different information at different well-defined times through the same lines. Advantage: fewer pins are needed on the processor.

  7. Q7.

    List any six salient features of 8086.

    Ans: (1) 16-bit processor released by Intel in 1978. (2) 16-bit data bus, 20-bit address bus. (3) Can address 1 MB memory and 64K IO ports. (4) 40-pin DIP, single +5 V supply. (5) Pipelined architecture with 6-byte instruction queue. (6) Segmented memory; works in minimum and maximum modes.

  8. Q8.

    What is the data size and address size of 8086?

    Ans: 8086 operates on 8-bit or 16-bit data. It uses a 20-bit address for memory and a 16-bit address for IO devices.

  9. Q9.

    How much memory can the 8086 address directly? Why?

    Ans: 1 MB, because it has 20 address lines and 2^20 = 1,048,576 bytes = 1 MB.

  10. Q10.

    How many IO ports can the 8086 address?

    Ans: 64K (2^16 = 65,536) IO ports, because it uses a 16-bit IO address.

  11. Q11.

    What is the difference between 8086 and 8088?

    Ans: 8086 has a 16-bit external data bus (accesses memory in words) and a 6-byte queue; 8088 has an 8-bit external data bus (accesses memory in bytes) and a 4-byte queue.

Pin Descriptions

  1. Q12.

    What are the two operating modes of 8086? How is the mode selected?

    Ans: Minimum mode (single processor) and maximum mode (multiprocessor). MN/MX pin tied HIGH selects minimum mode; tied LOW selects maximum mode.

  2. Q13.

    Explain the function of the M/IO signal.

    Ans: M/IO tells whether the address is a memory address or an IO address. It is HIGH for memory access and LOW for IO access.

  3. Q14.

    What is ALE? Why is it needed?

    Ans: ALE (Address Latch Enable) is used to enable an external latch to separate (demultiplex) the address from the multiplexed address/data lines AD0–AD15.

  4. Q15.

    What is the use of BHE and A0 signals?

    Ans: Memory is divided into an even (lower) bank and an odd (upper) bank. A0 = 0 selects the even bank and BHE = 0 selects the odd bank.

  5. Q16.

    How is the READY signal used?

    Ans: READY is an input used by slow devices. If READY is LOW when sampled in T2, the 8086 inserts wait states until READY goes HIGH.

  6. Q17.

    What are HOLD and HLDA signals?

    Ans: They are used for DMA. A DMA controller sends HOLD; the 8086 releases its buses (tristate) and replies with HLDA (Hold Acknowledge).

  7. Q18.

    What is the function of the TEST pin?

    Ans: TEST is checked by the WAIT instruction. The processor stays idle after WAIT until TEST is made LOW.

  8. Q19.

    What happens when the 8086 is reset?

    Ans: DS, SS, ES, IP and the flag register are cleared, CS is set to FFFFH and the queue is emptied. Execution starts from physical address FFFF0H.

  9. Q20.

    How is the clock signal given to the 8086? What is its maximum clock frequency?

    Ans: 8086 has no internal clock circuit; the 8284 clock generator supplies a clock with 33% duty cycle. Maximum internal clock of 8086 is 5 MHz (8086-2: 8 MHz, 8086-1: 10 MHz).

Block Diagram, Registers and Pipelining

  1. Q21.

    What are the two functional units of 8086?

    Ans: Bus Interface Unit (BIU) and Execution Unit (EU).

  2. Q22.

    List the functions of the BIU.

    Ans: The BIU fetches instructions, reads/writes data from memory and IO, computes the 20-bit physical address and keeps the instruction queue filled. It contains segment registers, IP and the queue.

  3. Q23.

    List the functions of the EU.

    Ans: The EU takes instructions from the queue, decodes and executes them. It contains the ALU, general purpose registers, pointer/index registers and the flag register.

  4. Q24.

    What is pipelining? How is it achieved in 8086?

    Ans: Pipelining means overlapping the fetch of the next instruction with the execution of the current one. In 8086 the BIU fetches and stores instructions in the queue while the EU executes, so both work at the same time.

  5. Q25.

    What is an instruction queue? What is its size in 8086?

    Ans: It is a FIFO (First-In-First-Out) group of registers that stores pre-fetched instruction bytes. In 8086 it is 6 bytes long.

  6. Q26.

    List the general purpose registers of 8086 and give one special use of each.

    Ans: AX – accumulator (multiply/divide, IO); BX – base register (memory pointer); CX – count register (LOOP, shift, string count); DX – data register (multiply/divide, IO port address).

  7. Q27.

    What are the pointer and index registers of 8086?

    Ans: SP (Stack Pointer), BP (Base Pointer), SI (Source Index) and DI (Destination Index).

  8. Q28.

    What is a flag? List the nine flags of 8086.

    Ans: A flag is a flip-flop that shows the status of the result or controls the processor. Status flags: CF, PF, AF, ZF, SF, OF. Control flags: TF, IF, DF.

  9. Q29.

    What are control flags? Explain each.

    Ans: TF (Trap) – enables single-step execution; IF (Interrupt) – enables/disables maskable interrupts (INTR); DF (Direction) – decides auto-increment (DF=0) or auto-decrement (DF=1) of SI/DI in string instructions.

Memory Segmentation and Physical Address

  1. Q30.

    What is memory segmentation?

    Ans: Dividing the 1 MB memory into logical blocks (segments) of up to 64 KB each. Four segments – code, data, stack and extra – can be active at a time.

  2. Q31.

    List the segment registers of 8086 and the default offset register used with each.

    Ans: CS – IP (code); SS – SP or BP (stack); DS – BX, SI or direct address (data); ES – DI (string destination).

  3. Q32.

    What is the difference between a segment register and a general purpose register?

    Ans: Segment registers hold the 16-bit base address of a segment. General purpose registers hold data, act as pointers or counters during computation.

  4. Q33.

    Give any three advantages of memory segmentation.

    Ans: (1) A 20-bit address is formed using 16-bit registers. (2) Code, data and stack are kept separate. (3) Programs are relocatable – they can be loaded anywhere by just changing segment register values.

  5. Q34.

    What is the maximum size of a segment? Why?

    Ans: 64 KB, because the offset (effective address) is 16 bits and 2^16 = 65,536 bytes.

  6. Q35.

    How is the 20-bit physical address calculated in 8086?

    Ans: Physical Address = Segment register × 10H (shift left by 4 bits) + Offset (effective address).

  7. Q36.

    If CS = 2000H and IP = 1234H, find the physical address of the next instruction.

    Ans: PA = 2000H × 10H + 1234H = 20000H + 1234H = 21234H.

  8. Q37.

    If DS = 3000H and the offset of a data item is 0050H, find its physical address.

    Ans: PA = 30000H + 0050H = 30050H.

  9. Q38.

    If SS = 4000H and SP = FFFEH, find the physical address of the top of stack.

    Ans: PA = 40000H + FFFEH = 4FFFEH.

  10. Q39.

    What are a bus cycle and a T-state?

    Ans: A bus cycle is one basic external operation (memory/IO read or write) done by the processor; it normally takes 4 T-states. A T-state is one period of the processor clock.

UNIT II : ALP Tools, Directives, Procedures & Macros

Program Development Steps

  1. Q1.

    What is a program? What is an assembly language program (ALP)?

    Ans: A program is a set of instructions written to perform a task. An ALP is a program written using mnemonics (e.g., MOV, ADD) of the processor.

  2. Q2.

    List the steps in developing an assembly language program.

    Ans: (1) Define the problem. (2) Write the algorithm. (3) Draw the flowchart. (4) Prepare the initialization checklist. (5) Choose instructions. (6) Convert the algorithm into ALP. (7) Assemble, link, run and debug.

  3. Q3.

    What is meant by problem definition?

    Ans: Clearly stating what the program must do – the inputs, the required processing and the expected output.

  4. Q4.

    What is an algorithm?

    Ans: An algorithm is a step-by-step written procedure to solve the problem in a finite number of steps.

  5. Q5.

    What is a flowchart?

    Ans: A flowchart is a graphical (pictorial) representation of the flow of operations of a program, i.e., the pictorial form of an algorithm.

  6. Q6.

    List any five symbols used in a flowchart.

    Ans: Oval – Start/End; Rectangle – Process; Diamond – Decision; Parallelogram – Input/Output; Small circle – Connector; Arrow – flow line.

  7. Q7.

    What is an initialization checklist?

    Ans: A list of items to be set before the main program starts: segment registers (DS, ES, SS), stack pointer, counters, pointers (SI/DI), flags (e.g., DF) and IO ports.

  8. Q8.

    What points are considered while choosing instructions for a program?

    Ans: Choose instructions that do the job correctly with the fewest bytes and clock cycles, and use the proper addressing mode for the data.

ALP Development Tools and EMU8086

  1. Q9.

    What are program development tools? Name them.

    Ans: Software used to write, translate, test and correct programs: editor, assembler, linker, locator, debugger, simulator and emulator.

  2. Q10.

    What is an editor?

    Ans: A program used to type and modify the assembly language source program and save it as a file (e.g., PROG.ASM).

  3. Q11.

    What is an assembler? Why is it needed?

    Ans: An assembler translates assembly language (mnemonics) into machine code (object file). It is needed because the processor understands only binary machine code.

  4. Q12.

    Give any four advantages of an assembler.

    Ans: (1) Translates mnemonics fast and accurately. (2) Allows labels and variables. (3) Detects syntax errors. (4) Reserves memory for data and gives a list file for documentation.

  5. Q13.

    What is the difference between a one-pass and a two-pass assembler?

    Ans: A one-pass assembler reads the source once and cannot handle forward references. A two-pass assembler assigns addresses to labels in pass 1 and generates machine code in pass 2, so forward references are allowed.

  6. Q14.

    What is a linker?

    Ans: A linker joins one or more object files into a single executable file (.EXE) and resolves references between them.

  7. Q15.

    What is a debugger? What is debugging?

    Ans: A debugger is software used to find and correct errors in a program (single-step, breakpoints, view registers/memory). The process of finding and correcting errors is called debugging.

  8. Q16.

    What is the difference between a simulator and an emulator?

    Ans: A simulator checks only the software by imitating the processor on a PC. An emulator tests both the hardware and software of a new microprocessor system.

  9. Q17.

    Explain the integrated workflow of EMU8086.

    Ans: In EMU8086: (1) type the program in the built-in editor, (2) click Compile/Emulate to assemble and load it, (3) Run or Single-Step the program, (4) watch registers, flags and memory to check the result and fix errors.

Assembler Directives

  1. Q18.

    What are assembler directives? Why are they called pseudo-instructions?

    Ans: Directives are instructions to the assembler (not to the processor) about the program – start/end, segments, data and storage. They produce no machine code, so they are called pseudo-instructions.

  2. Q19.

    Explain the data-defining directives DB, DW and DD with an example.

    Ans: DB defines byte(s), DW defines word(s) (2 bytes), DD defines double word(s) (4 bytes). Example: NUM1 DB 25H; NUM2 DW 1234H; NUM3 DD 12345678H.

  3. Q20.

    What is the use of DUP? Give an example.

    Ans: DUP repeats a value to reserve memory. Example: ARR DB 10 DUP(0) reserves 10 bytes, all set to 0. RES DW 5 DUP(?) reserves 5 uninitialized words.

  4. Q21.

    Explain the EQU directive.

    Ans: EQU assigns a name to a constant value. Example: COUNT EQU 05H. No memory is allotted; the assembler replaces COUNT with 05H.

  5. Q22.

    What is the function of the ORG and END directives?

    Ans: ORG sets the starting address (offset) for the code or data that follows, e.g., ORG 100H. END marks the end of the source program.

  6. Q23.

    Explain the SEGMENT and ENDS directives.

    Ans: SEGMENT marks the start of a logical segment and ENDS marks its end. Example: DATA SEGMENT ... DATA ENDS.

  7. Q24.

    What is the purpose of the ASSUME directive?

    Ans: ASSUME tells the assembler which segment register is associated with which segment. Example: ASSUME CS:CODE, DS:DATA. It does not load the registers; DS must still be loaded by MOV instructions.

  8. Q25.

    What are simplified segment directives? Explain .MODEL, .DATA, .CODE and .STACK.

    Ans: .MODEL selects the memory model (e.g., SMALL – one code and one data segment). .DATA starts the data segment, .CODE starts the code segment, and .STACK reserves the stack (e.g., .STACK 100H).

  9. Q26.

    Write the two instructions used to initialize DS in a program.

    Ans: MOV AX, @DATA (or MOV AX, DATA) followed by MOV DS, AX. A segment register cannot be loaded with immediate data directly.

Procedures

  1. Q27.

    What is a procedure (subroutine)?

    Ans: A group of instructions written separately to perform a task that is needed many times. It is called from the main program using CALL and returns using RET.

  2. Q28.

    Explain the PROC and ENDP directives.

    Ans: PROC marks the start of a procedure with its name and type (NEAR/FAR); ENDP marks its end. Example: ADDNUM PROC NEAR ... RET ... ADDNUM ENDP.

  3. Q29.

    What are NEAR and FAR procedures?

    Ans: A NEAR procedure is in the same code segment as the calling program (only IP is saved on stack). A FAR procedure is in a different code segment (both CS and IP are saved).

  4. Q30.

    Explain the operation of CALL and RET instructions.

    Ans: CALL pushes the return address (IP, or CS and IP for far call) onto the stack and jumps to the procedure. RET pops the return address from the stack back into IP (and CS), so the main program continues.

  5. Q31.

    List the methods of passing parameters to a procedure.

    Ans: Parameters can be passed through (1) registers, (2) memory locations (variables), (3) pointers (address in a register), and (4) the stack.

  6. Q32.

    Give any three advantages of procedures.

    Ans: (1) Modular programming. (2) Saves memory since the code is written once. (3) Reduces program development time and makes debugging easier.

Macros

  1. Q33.

    What is a macro? Give its syntax.

    Ans: A macro is a group of instructions given a name; the name is written wherever the group is needed. Syntax: name MACRO [parameters] ... ENDM.

  2. Q34.

    What is meant by macro expansion?

    Ans: During assembly, the assembler replaces each macro call with the actual instructions of the macro. This is called expanding the macro.

  3. Q35.

    What is a macro with parameters? Give an example.

    Ans: A macro that accepts values when called. Example: DISP MACRO MSG / LEA DX, MSG / MOV AH, 09H / INT 21H / ENDM. It is called as DISP STR1.

  4. Q36.

    Give two differences between a macro and a procedure.

    Ans: (1) Macro code is copied at every call, so it uses more memory; a procedure is stored only once. (2) A macro needs no CALL/RET, so it runs faster; a procedure uses CALL/RET and the stack.

  5. Q37.

    What is the disadvantage of a macro?

    Ans: If a macro is used many times, the program becomes large and occupies more memory.

UNIT III & IV : Instruction Set and Programming

Machine Language Instruction Format

  1. Q1.

    What is the size of 8086 instructions?

    Ans: One to six bytes. The first byte has the opcode and special bits, the second byte gives the addressing mode, and the remaining bytes hold displacement or immediate data.

  2. Q2.

    Write the general format of an 8086 instruction.

    Ans: Byte 1: Opcode | d | w; Byte 2: mod | reg | r/m; Bytes 3–4: low/high displacement or data; Bytes 5–6: low/high data.

  3. Q3.

    What is the function of the W-bit and D-bit in an 8086 instruction?

    Ans: W-bit: W = 0 byte operation, W = 1 word operation. D-bit: D = 1 the register in the reg field is the destination; D = 0 it is the source.

  4. Q4.

    What do the MOD, REG and R/M fields indicate?

    Ans: MOD (2 bits) gives the addressing mode/displacement size (MOD = 11 means register mode). REG (3 bits) names a register operand. R/M (3 bits) names the other operand – a register or a memory addressing combination.

  5. Q5.

    List the six groups of 8086 instructions.

    Ans: Data transfer, arithmetic, logical (bit manipulation), string, program execution (control) transfer, and processor control instructions.

Addressing Modes

  1. Q6.

    What is addressing? What is an addressing mode?

    Ans: The method of specifying the data (operand) for an instruction is called addressing; the different ways of doing it are called addressing modes.

  2. Q7.

    List the addressing modes of 8086.

    Ans: Register, immediate, direct, register indirect, based, indexed, based indexed, string, direct IO port, indirect IO port, relative and implied addressing.

  3. Q8.

    What is register addressing? Give an example.

    Ans: The operand is in a register. Example: MOV CX, DX – the content of DX is copied to CX.

  4. Q9.

    What is immediate addressing? Give an example.

    Ans: The data is given in the instruction itself. Example: MOV BX, 0CA5H – 0CA5H is loaded into BX.

  5. Q10.

    Explain direct addressing with an example.

    Ans: The 16-bit offset (effective address) of the data is given in the instruction. Example: MOV CL, [0F2AH] – the byte at DS:0F2AH is copied to CL.

  6. Q11.

    Explain register indirect addressing with an example.

    Ans: The offset of the data is held in a register (BX, SI or DI). Example: MOV DX, [DI] – the word at DS:DI is copied to DX.

  7. Q12.

    Explain based and indexed addressing.

    Ans: Based: EA = BX or BP + displacement, e.g., MOV CX, [BP+04H] (BP uses SS). Indexed: EA = SI or DI + displacement, e.g., MOV AX, [SI+04H] (uses DS).

  8. Q13.

    What is based indexed addressing? Give an example.

    Ans: EA = base register (BX/BP) + index register (SI/DI) + displacement. Example: MOV CX, [BX+SI+10H].

  9. Q14.

    Explain string addressing.

    Ans: Used by string instructions: the source is at DS:SI and the destination is at ES:DI. SI and DI are automatically incremented (DF = 0) or decremented (DF = 1).

  10. Q15.

    How are IO ports addressed in 8086?

    Ans: Direct: an 8-bit port address is given in the instruction, e.g., IN AL, 80H. Indirect: a 16-bit port address is kept in DX, e.g., OUT DX, AL.

  11. Q16.

    What are relative and implied addressing?

    Ans: Relative: the target address is given as a signed displacement from IP, e.g., JC NEXT. Implied: the operand is implied by the instruction itself, e.g., CLC, STD.

  12. Q17.

    Identify the addressing mode: (a) MOV AX, 1234H (b) MOV AX, [BX+SI] (c) MOV AL, [2000H] (d) ADD AX, BX.

    Ans: (a) Immediate (b) Based indexed (c) Direct (d) Register.

Data Transfer Instructions

  1. Q18.

    What operations are performed by data transfer instructions?

    Ans: Copy register to register, register to/from memory, accumulator to/from port, exchange data, load immediate data and load effective address or segment registers.

  2. Q19.

    Which data transfer instructions affect the flags?

    Ans: Only POPF and SAHF affect the flags.

  3. Q20.

    What happens to SP after a PUSH and after a POP?

    Ans: PUSH decrements SP by 2 and then stores the word. POP reads the word and then increments SP by 2.

  4. Q21.

    List the IO instructions of 8086.

    Ans: IN AL/AX, port8; IN AL/AX, DX; OUT port8, AL/AX; OUT DX, AL/AX. IN reads from a port into the accumulator; OUT sends the accumulator to a port.

  5. Q22.

    Explain the instruction LEA reg16, mem.

    Ans: LEA loads the effective address (offset) of the memory operand into the register – not its content. Example: LEA SI, ARRAY loads the offset of ARRAY into SI.

  6. Q23.

    Explain XCHG and XLAT instructions.

    Ans: XCHG exchanges the contents of two registers or a register and memory, e.g., XCHG AX, BX. XLAT replaces AL with the byte at DS:[BX + AL] (table look-up).

  7. Q24.

    How can the flag register be modified in 8086?

    Ans: Low byte: load AH and use SAHF. Whole 16-bit register: load a register, PUSH it, then POPF.

Arithmetic Instructions

  1. Q25.

    What operations are performed by arithmetic instructions?

    Ans: Addition and subtraction of binary, BCD and ASCII data; multiplication and division of signed and unsigned numbers; increment, decrement, negate and compare.

  2. Q26.

    What is the difference between ADD and ADC?

    Ans: ADD adds source to destination. ADC adds source, destination and the carry flag – used for multi-byte (e.g., 32-bit) addition.

  3. Q27.

    How is subtraction performed in 8086? How is the result interpreted?

    Ans: By 2's complement addition. If CF = 1 after SUB, the result is negative (in 2's complement form); if CF = 0, it is positive.

  4. Q28.

    What is the similarity and difference between SUB and CMP?

    Ans: Both subtract and set the flags. SUB stores the result in the destination; CMP discards the result and only changes flags.

  5. Q29.

    Explain MUL and IMUL instructions.

    Ans: MUL multiplies unsigned numbers and IMUL signed numbers. Byte: AL × source → AX. Word: AX × source → DX:AX.

  6. Q30.

    Explain DIV and IDIV instructions.

    Ans: DIV (unsigned) and IDIV (signed). Byte: AX ÷ source → AL = quotient, AH = remainder. Word: DX:AX ÷ source → AX = quotient, DX = remainder.

  7. Q31.

    What is the status of flags after multiplication and division?

    Ans: All six arithmetic flags may change; after division they are undefined. (After MUL, CF and OF show whether the upper half of the result is non-zero.)

  8. Q32.

    What is the use of DAA and AAA instructions?

    Ans: DAA (Decimal Adjust after Addition) corrects AL after adding two packed BCD numbers. AAA (ASCII Adjust after Addition) corrects AL after adding two ASCII/unpacked BCD digits.

  9. Q33.

    What do CBW and CWD instructions do?

    Ans: CBW copies bit 7 of AL into all bits of AH (byte to word). CWD copies bit 15 of AX into all bits of DX (word to double word). Used before signed division.

  10. Q34.

    What is the difference between INC/DEC and NEG?

    Ans: INC adds 1 and DEC subtracts 1 from the operand (CF not affected). NEG replaces the operand by its 2's complement.

Bit Manipulation Instructions

  1. Q35.

    What operations are performed by logical (bit manipulation) instructions?

    Ans: AND, OR, XOR, NOT, TEST, shift (SHL/SAL, SHR, SAR) and rotate (ROL, ROR, RCL, RCR).

  2. Q36.

    What is the difference between CMP and TEST?

    Ans: CMP subtracts the operands; TEST ANDs them bit by bit. Both only change flags – the operands are not altered.

  3. Q37.

    What is the difference between NOT and NEG?

    Ans: NOT gives the 1's complement (inverts every bit). NEG gives the 2's complement (NOT + 1).

  4. Q38.

    What is the difference between arithmetic shift and logical shift?

    Ans: Logical shift fills the empty bit with 0. Arithmetic right shift (SAR) copies the sign bit into the MSB to keep the sign. Left shifts (SHL/SAL) are the same.

  5. Q39.

    What is the difference between shift and rotate?

    Ans: In shift, a 0 (or sign bit) is inserted and the bit shifted out is lost into CF. In rotate, the bit shifted out is fed back to the other end (directly or through CF), so no bit is lost.

  6. Q40.

    What is the difference between ROL and RCL?

    Ans: ROL rotates left and copies the MSB into both LSB and CF. RCL rotates left through carry: MSB goes into CF and the old CF goes into LSB.

  7. Q41.

    How is the count for a shift/rotate specified in 8086?

    Ans: For one bit, write 1 as the count (e.g., SHL AL, 1). For more than one bit, load the count in CL (e.g., MOV CL, 04H / SHL AL, CL).

Compare (CMP) and Test (TEST) Instructions

  1. Q42.

    What is the function of the CMP instruction? Give an example.

    Ans: CMP destination, source subtracts the source from the destination only to set the flags (CF, ZF, SF, OF, PF, AF). The result is not stored, so both operands are unchanged. Example: CMP AL, BL.

  2. Q43.

    What is the status of CF and ZF after CMP AL, BL (unsigned numbers)?

    Ans: AL > BL: CF = 0, ZF = 0. AL = BL: CF = 0, ZF = 1. AL < BL: CF = 1, ZF = 0.

  3. Q44.

    If AL = 35H and BL = 50H, what are CF, ZF, SF and AL after CMP AL, BL?

    Ans: 35H − 50H = E5H (borrow). So CF = 1, ZF = 0, SF = 1. AL remains 35H because CMP does not store the result.

  4. Q45.

    Which conditional jumps are used after CMP for unsigned and for signed numbers?

    Ans: Unsigned: JA/JNBE, JAE/JNB, JB/JNAE, JBE/JNA. Signed: JG/JNLE, JGE/JNL, JL/JNGE, JLE/JNG. For both: JE/JZ and JNE/JNZ.

  5. Q46.

    What is the difference between JA and JG?

    Ans: JA (Jump if Above) is for unsigned numbers and jumps when CF = 0 and ZF = 0. JG (Jump if Greater) is for signed numbers and jumps when ZF = 0 and SF = OF.

  6. Q47.

    What is the function of the TEST instruction? Give an example.

    Ans: TEST destination, source ANDs the two operands bit by bit only to set the flags (ZF, SF, PF; CF = OF = 0). The result is not stored. Example: TEST AL, 01H checks bit 0 of AL.

  7. Q48.

    What is the difference between AND and TEST?

    Ans: Both do a bit-wise AND and set the flags. AND stores the result in the destination; TEST discards the result, so the destination is unchanged.

  8. Q49.

    How can you check whether the number in AL is odd or even using TEST?

    Ans: TEST AL, 01H then JZ EVEN. If bit 0 is 0 the result is zero (ZF = 1), so the number is even; otherwise (ZF = 0) it is odd.

  9. Q50.

    How can you check whether the number in AL is positive or negative using TEST?

    Ans: TEST AL, 80H then JNZ NEGATIVE. Bit 7 is the sign bit; if it is 1 the result is non-zero (ZF = 0) and the number is negative.

  10. Q51.

    If AL = 95H, what are ZF and SF after TEST AL, 80H?

    Ans: 95H AND 80H = 80H, which is non-zero, so ZF = 0 and SF = 1. AL remains 95H.

  11. Q52.

    How can you check whether AX is zero without changing it?

    Ans: Use TEST AX, AX or CMP AX, 0000H, then JZ. ZF = 1 means AX is zero.

  12. Q53.

    What is masking? How are AND, OR and XOR used for it?

    Ans: Masking means changing only selected bits. AND clears bits (AND AL, 0FH clears the upper nibble), OR sets bits (OR AL, 30H converts 0–9 to ASCII), XOR complements bits (XOR AL, 0FFH inverts all bits).

  13. Q54.

    Why is XOR AX, AX used in programs?

    Ans: It clears AX to 0000H and also clears CF and OF. It is shorter (2 bytes) than MOV AX, 0000H (3 bytes).

  14. Q55.

    What is the difference between CMP and CMPSB?

    Ans: CMP compares a register/memory with a register, memory or immediate data. CMPSB compares the byte at DS:SI with the byte at ES:DI and then updates SI and DI automatically; it is used with REPE/REPNE for strings.

String Instructions

  1. Q56.

    What operations are performed by string instructions?

    Ans: Move a byte/word from DS:SI to ES:DI, compare two strings, scan a string for a value, load from string into accumulator and store accumulator into a string.

  2. Q57.

    List the string instructions of 8086.

    Ans: MOVSB/MOVSW, CMPSB/CMPSW, SCASB/SCASW, LODSB/LODSW, STOSB/STOSW, and the prefixes REP, REPE/REPZ, REPNE/REPNZ.

  3. Q58.

    What is the use of the REP prefix?

    Ans: REP repeats the following string instruction CX times (CX is decremented each time). REPE/REPZ repeats while equal (ZF = 1) and REPNE/REPNZ repeats while not equal (ZF = 0).

  4. Q59.

    Which instructions affect the direction flag and what is its role?

    Ans: CLD (DF = 0, auto-increment), STD (DF = 1, auto-decrement) and POPF. DF decides whether SI/DI move forward or backward in string operations.

Program Execution Transfer, Branch and Loop Instructions

  1. Q60.

    What is the difference between conditional and unconditional branch instructions?

    Ans: Unconditional (JMP) always transfers control. Conditional (JZ, JC, JNZ etc.) transfers control only if the flag condition is true; otherwise the next instruction runs.

  2. Q61.

    What are near jump and far jump?

    Ans: Near jump: target in the same code segment (only IP changes). Far jump: target in another segment (both CS and IP change).

  3. Q62.

    What are near call and far call?

    Ans: Near call: procedure in the same code segment – only IP is pushed. Far call: procedure in another segment – CS and IP are pushed.

  4. Q63.

    What is the difference between CALL and JMP?

    Ans: CALL saves the return address on the stack before branching, so control can come back with RET. JMP does not save any return address.

  5. Q64.

    What is the difference between CALL and INT?

    Ans: CALL saves IP (and CS) on the stack. INT saves the flag register, CS and IP, and gets the new address from the interrupt vector table.

  6. Q65.

    List any six conditional jump instructions with their conditions.

    Ans: JZ/JE (ZF=1), JNZ/JNE (ZF=0), JC (CF=1), JNC (CF=0), JS (SF=1), JO (OF=1).

  7. Q66.

    Explain the LOOP instruction.

    Ans: LOOP label decrements CX by 1 and jumps to the label if CX ≠ 0; when CX = 0 the next instruction runs. It replaces DEC CX + JNZ.

  8. Q67.

    Explain LOOPE/LOOPZ and LOOPNE/LOOPNZ.

    Ans: LOOPE/LOOPZ: decrement CX, loop while CX ≠ 0 and ZF = 1. LOOPNE/LOOPNZ: decrement CX, loop while CX ≠ 0 and ZF = 0.

  9. Q68.

    What is the use of JCXZ?

    Ans: JCXZ jumps to the label if CX = 0. It is used to skip a loop when the count is zero.

Processor Control Instructions

  1. Q69.

    List the flag manipulation instructions of 8086.

    Ans: CLC, STC, CMC (carry flag); CLD, STD (direction flag); CLI, STI (interrupt flag).

  2. Q70.

    Explain HLT and NOP instructions.

    Ans: HLT stops the processor until an interrupt or reset occurs. NOP does no operation; it only takes 3 clock cycles and is used for delay or to reserve space.

  3. Q71.

    Explain WAIT, LOCK and ESC instructions.

    Ans: WAIT makes the processor idle until TEST pin goes LOW. LOCK is a prefix that makes the LOCK pin active so other processors cannot take the bus. ESC passes an instruction to a coprocessor such as 8087.

Assembly Language Programming (Simple Programs)

  1. Q72.

    Write the general structure of an 8086 ALP using simplified segment directives.

    Ans: Every program below follows this structure (EMU8086 / MASM). DS is loaded first; INT 21H function 4CH returns to DOS.

    .MODEL SMALL
.STACK 100H
.DATA
    ; variables here
.CODE
START: MOV AX, @DATA
       MOV DS, AX       ; initialise DS
       ; program here
       MOV AH, 4CH
       INT 21H          ; exit to DOS
END START
  2. Q73.

    Write an ALP to add two 8-bit numbers.

    Ans: Result: RES = 37H.

    .MODEL SMALL
.DATA
  N1  DB 25H
  N2  DB 12H
  RES DB ?
.CODE
START: MOV AX, @DATA
       MOV DS, AX
       MOV AL, N1
       ADD AL, N2       ; AL = 25H + 12H
       MOV RES, AL
       MOV AH, 4CH
       INT 21H
END START
  3. Q74.

    Write an ALP to add two 16-bit numbers and store the carry.

    Ans: Result: SUM = 0000H, CARRY = 01H.

    .MODEL SMALL
.DATA
  N1    DW 0FFFFH
  N2    DW 0001H
  SUM   DW ?
  CARRY DB 00H
.CODE
START: MOV AX, @DATA
       MOV DS, AX
       MOV AX, N1
       ADD AX, N2
       MOV SUM, AX
       JNC SKIP          ; no carry -> skip
       INC CARRY
SKIP:  MOV AH, 4CH
       INT 21H
END START
  4. Q75.

    Write an ALP to multiply two 8-bit unsigned numbers.

    Ans: The 16-bit product is in AX. Result: RES = 00EAH (12H × 0DH = 18 × 13 = 234).

    .MODEL SMALL
.DATA
  N1  DB 12H
  N2  DB 0DH
  RES DW ?
.CODE
START: MOV AX, @DATA
       MOV DS, AX
       MOV AL, N1
       MUL N2           ; AX = AL x N2
       MOV RES, AX
       MOV AH, 4CH
       INT 21H
END START
  5. Q76.

    Write an ALP to divide a 16-bit number by an 8-bit number.

    Ans: 100 ÷ 7: Quotient QUO = 0EH (14), Remainder REM = 02H.

    .MODEL SMALL
.DATA
  DVD DW 0064H       ; 100
  DVS DB 07H
  QUO DB ?
  REM DB ?
.CODE
START: MOV AX, @DATA
       MOV DS, AX
       MOV AX, DVD
       DIV DVS          ; AL = quotient, AH = remainder
       MOV QUO, AL
       MOV REM, AH
       MOV AH, 4CH
       INT 21H
END START
  6. Q77.

    Write an ALP to compare two numbers and store the larger one (use CMP).

    Ans: Result: BIG = 47H.

    .MODEL SMALL
.DATA
  N1  DB 2AH
  N2  DB 47H
  BIG DB ?
.CODE
START: MOV AX, @DATA
       MOV DS, AX
       MOV AL, N1
       CMP AL, N2       ; flags only, AL unchanged
       JAE STORE        ; AL >= N2 -> AL is larger
       MOV AL, N2
STORE: MOV BIG, AL
       MOV AH, 4CH
       INT 21H
END START
  7. Q78.

    Write an ALP to find the largest number in an array of five bytes.

    Ans: Result: LARGE = 89H.

    .MODEL SMALL
.DATA
  ARR   DB 12H, 45H, 07H, 89H, 23H
  LARGE DB ?
.CODE
START: MOV AX, @DATA
       MOV DS, AX
       LEA SI, ARR
       MOV CX, 04H      ; 5 elements -> 4 comparisons
       MOV AL, [SI]
UP:    INC SI
       CMP AL, [SI]
       JAE NEXT
       MOV AL, [SI]     ; new largest
NEXT:  LOOP UP
       MOV LARGE, AL
       MOV AH, 4CH
       INT 21H
END START
  8. Q79.

    Write an ALP to count the even and odd numbers in an array (use TEST).

    Ans: 24H, 48H and 52H are even; 11H and 37H are odd. Result: ECOUNT = 03H, OCOUNT = 02H.

    .MODEL SMALL
.DATA
  ARR    DB 11H, 24H, 37H, 48H, 52H
  ECOUNT DB 00H
  OCOUNT DB 00H
.CODE
START: MOV AX, @DATA
       MOV DS, AX
       LEA SI, ARR
       MOV CX, 05H
UP:    TEST BYTE PTR [SI], 01H   ; check bit 0
       JZ  EVN                   ; ZF = 1 -> even
       INC OCOUNT
       JMP NEXT
EVN:   INC ECOUNT
NEXT:  INC SI
       LOOP UP
       MOV AH, 4CH
       INT 21H
END START
  9. Q80.

    Write an ALP to check whether a number is positive or negative (use TEST).

    Ans: For NUM = 0F5H bit 7 is 1, so RES = 'N'.

    .MODEL SMALL
.DATA
  NUM DB 0F5H
  RES DB ?
.CODE
START: MOV AX, @DATA
       MOV DS, AX
       MOV AL, NUM
       TEST AL, 80H     ; check sign bit
       JNZ NEGV
       MOV RES, 'P'     ; positive
       JMP DONE
NEGV:  MOV RES, 'N'     ; negative
DONE:  MOV AH, 4CH
       INT 21H
END START
  10. Q81.

    Write an ALP to find the sum of an array of five 8-bit numbers (16-bit result).

    Ans: Result: SUM = 00F0H.

    .MODEL SMALL
.DATA
  ARR DB 10H, 20H, 30H, 40H, 50H
  SUM DW ?
.CODE
START: MOV AX, @DATA
       MOV DS, AX
       XOR AX, AX       ; AX = 0
       LEA SI, ARR
       MOV CX, 05H
UP:    ADD AL, [SI]
       ADC AH, 00H      ; add carry to upper byte
       INC SI
       LOOP UP
       MOV SUM, AX
       MOV AH, 4CH
       INT 21H
END START
  11. Q82.

    Write an ALP to count the number of 1s in a byte (use rotate).

    Ans: NUM = 0A7H = 1010 0111B, so ONES = 05H.

    .MODEL SMALL
.DATA
  NUM  DB 0A7H
  ONES DB ?
.CODE
START: MOV AX, @DATA
       MOV DS, AX
       MOV AL, NUM
       MOV BL, 00H
       MOV CX, 08H
UP:    ROR AL, 1        ; LSB goes to CF
       JNC NEXT
       INC BL
NEXT:  LOOP UP
       MOV ONES, BL
       MOV AH, 4CH
       INT 21H
END START
  12. Q83.

    Write an ALP to transfer a block of five bytes using a string instruction.

    Ans: After execution DST holds 10H, 20H, 30H, 40H, 50H. ES must point to the same segment as DS.

    .MODEL SMALL
.DATA
  SRC DB 10H, 20H, 30H, 40H, 50H
  DST DB 5 DUP(0)
.CODE
START: MOV AX, @DATA
       MOV DS, AX
       MOV ES, AX       ; ES needed for DI
       LEA SI, SRC
       LEA DI, DST
       MOV CX, 05H
       CLD              ; auto-increment
       REP MOVSB
       MOV AH, 4CH
       INT 21H
END START
  13. Q84.

    Write an ALP to display a message on the screen using INT 21H.

    Ans: Function 09H of INT 21H displays a string ending with '$'; DX holds its offset.

    .MODEL SMALL
.DATA
  MSG DB 'WELCOME TO 8086$'
.CODE
START: MOV AX, @DATA
       MOV DS, AX
       LEA DX, MSG
       MOV AH, 09H      ; display string
       INT 21H
       MOV AH, 4CH
       INT 21H
END START

UNIT V : Peripheral Devices and Interfacing

Programmable Peripheral Devices and Data Transfer

  1. Q1.

    What is a programmable peripheral device?

    Ans: A peripheral device whose function can be changed by a program, by writing a control word into its control register. Examples: 8255, 8251, 8254, 8279, 8257.

  2. Q2.

    Why are peripheral devices (interfacing) needed?

    Ans: IO devices are slow and their signals do not match the processor. Interface devices match speed and signals, and free the processor from routine tasks.

  3. Q3.

    How are programmable peripheral devices classified?

    Ans: Parallel interface (8255), serial interface (8251 USART), DMA controller (8237/8257), keyboard/display controller (8279), timer/counter (8254), and data converters (DAC 0800, ADC 0809).

  4. Q4.

    What is the difference between parallel and serial data transfer?

    Ans: Parallel: all bits of a byte are sent at the same time on separate lines – fast, short distance. Serial: bits are sent one after another on a single line – slower, but cheap for long distance.

Programmable Peripheral Interface – Intel 8255

  1. Q5.

    What are the ports available in 8255?

    Ans: Three 8-bit ports – Port A, Port B and Port C. Port C can be used as two 4-bit ports (upper and lower).

  2. Q6.

    What are the operating modes of 8255?

    Ans: Mode 0 – simple IO; Mode 1 – strobed (handshake) IO; Mode 2 – bidirectional IO (Port A only). There is also the BSR mode.

  3. Q7.

    What is BSR mode of 8255? How is it selected?

    Ans: In Bit Set/Reset mode any single pin of Port C can be set or reset. It is selected when bit D7 of the control word is 0 (D7 = 1 selects the IO mode).

  4. Q8.

    What are the functions of Port C of 8255?

    Ans: It can be an 8-bit port or two 4-bit ports in mode 0, provides handshake signals in modes 1 and 2, and its pins can be individually set/reset in BSR mode.

  5. Q9.

    What is a handshake port?

    Ans: A port in which control signals are exchanged between the device and the processor to confirm that data is ready or has been taken (e.g., STB, IBF, OBF, ACK in 8255).

DMA Data Transfer – Intel 8237/8257

  1. Q10.

    What is DMA? How is it initiated?

    Ans: DMA (Direct Memory Access) transfers data directly between memory and IO without the processor. The IO device requests the DMA controller, which sends HOLD to 8086; the 8086 replies with HLDA and gives up the bus.

  2. Q11.

    What are the types of DMA transfer?

    Ans: Cycle stealing (single transfer), block (burst) transfer and demand transfer.

  3. Q12.

    Give any three features of the 8257 DMA controller.

    Ans: (1) Four independent DMA channels. (2) Each channel has a 16-bit address register and a 14-bit count register (up to 16K bytes). (3) Has mode set and status registers and priority logic.

Serial Communication – USART Intel 8251A

  1. Q13.

    What is the difference between synchronous and asynchronous serial transmission?

    Ans: Synchronous: data is sent as blocks with sync characters and a common clock. Asynchronous: each character is sent with a start bit and stop bit(s), no common clock.

  2. Q14.

    What is baud rate?

    Ans: Baud rate is the rate at which serial data bits are transmitted (bits per second when each signal element carries one bit).

  3. Q15.

    What is a USART? What are the functions of 8251A?

    Ans: A USART is a Universal Synchronous Asynchronous Receiver Transmitter. 8251A converts parallel data to serial (transmit) and serial to parallel (receive) in synchronous or asynchronous mode.

  4. Q16.

    What are the control words of 8251A?

    Ans: Mode word – sets baud rate factor, character length, parity and stop bits. Command word – enables transmit/receive, resets errors etc.

Keyboard / Display Interface – Intel 8279

  1. Q17.

    What is key debouncing?

    Ans: When a key is pressed its contacts bounce for 10–20 ms. Waiting for the bouncing to stop before reading the key, so that one key press gives only one code, is called debouncing.

  2. Q18.

    List the functions of 8279.

    Ans: Keyboard scanning, key debouncing, key code generation, informing the CPU of a key press, storing display codes and refreshing the display.

  3. Q19.

    What are the scan modes of 8279?

    Ans: Decoded scan – scan lines act like a 2-to-4 decoder output (4 lines). Encoded scan – scan lines give a binary count, decoded by an external decoder (up to 16 digits).

  4. Q20.

    What is the advantage of using 8279 instead of ports for keyboard and display?

    Ans: 8279 does scanning, debouncing and display refreshing by itself, so the processor time is saved for computing.

Programmable Timer – Intel 8254

  1. Q21.

    Give the main features of 8254.

    Ans: Three independent 16-bit down counters, each with CLK, GATE and OUT pins; counts in binary or BCD; six programmable modes.

  2. Q22.

    List the operating modes of 8254.

    Ans: Mode 0 – interrupt on terminal count; Mode 1 – hardware retriggerable one-shot; Mode 2 – rate generator; Mode 3 – square wave generator; Mode 4 – software triggered strobe; Mode 5 – hardware triggered strobe.

  3. Q23.

    What is the function of the GATE signal in 8254?

    Ans: GATE starts, stops or maintains counting. In modes 0, 2, 3, 4 it must stay HIGH to count; in modes 1 and 5 a LOW-to-HIGH edge on GATE starts (triggers) counting.

DAC 0800 and ADC 0809 Interfacing

  1. Q24.

    What is resolution of a DAC? Find the resolution of an 8-bit DAC with VREF = 5 V.

    Ans: Resolution is the smallest analog change for a 1-bit change of input = VREF / 2^n. For 8 bits and 5 V: 5 / 256 ≈ 19.5 mV.

  2. Q25.

    Give the main features of DAC 0800.

    Ans: 8-bit DAC, current output (an op-amp converts it to voltage), fast settling time of about 100 ns, works with ±5 V to ±18 V supply.

  3. Q26.

    Give the main features of ADC 0809.

    Ans: 8-bit successive approximation ADC with an 8-channel analog multiplexer (IN0–IN7), 28-pin IC, channel selected by address lines A, B, C, conversion time about 100 µs.

  4. Q27.

    What is the role of SOC, EOC and ALE in ADC 0809?

    Ans: ALE latches the channel address (A, B, C). SOC (Start Of Conversion) starts conversion. EOC (End Of Conversion) goes HIGH when conversion is complete, after which the data is read with OE.

  5. Q28.

    What are resolution and conversion time of an ADC?

    Ans: Resolution is the smallest analog change that changes the digital output by 1 LSB (VREF / 2^n). Conversion time is the time taken to convert an analog input into its digital value.
